Краткий ответ: нет, в текущей конфиге дебаф веномансеров не режет реген и не режет лайфстил.

Разбираем boss_venomancer_poison_sting (способность мобов-веномансеров и самого босса-веномансера, scripts/npc/bosses/boss_venom.txt, наследует venomancer_poison_sting):


"damage"            "250 450 600"   // DoT в секунду
"movement_speed"    "-16 -18 -20"   // замедление
"hp_regen_reduction"
{
    "value"         "0"              // ← реген-редукция ПО УМОЛЧАНИЮ 0
    "special_bonus_unique_venomancer_poisonsting_regen_reduction" "+20"
}
Что это значит:

Реген: поле hp_regen_reduction равно 0. То есть без прокачки таланта реген вообще не уменьшается. Режет реген только если взят талант poisonsting_regen_reduction (+20%). А у мобов-веномансеров и босса этот талант не прописан в юнит-конфиге, значит на практике реген не режется.
Лайфстил: у нативного venomancer_poison_sting вообще нет параметра, режущего лайфстил. Способность только DoT + замедление + (опц. через талант) реген-редукция. Лайфстил не затрагивается.
Отдельно: есть модификатор modifier_round_scaling_heal_reduction (он накидывается на всех мобов с wave >=4 — см. spawner), который режет heal amplify и hp regen amplify на -50%. Но это круговой scaling-ауры, а не дебаф конкретно веномансера, и он тоже не трогает лайфстил (только хил/реген-амплify, не сам лайфстил).

Итог: дебаф веномансера = чистый DoT + slow. Реген не режет (значение 0), лайфстил не режет вовсе. Если хочешь, чтобы веномансеры реально резали реген — надо в boss_venom.txt поставить hp_regen_reduction value > 0 (нужен Act mode для правки).

1. Скалирование врагов по числу игроков
Сейчас modifier_round_scaling одинаков для любого числа игроков. Добавим фактор игроков (базис = 2 человека, под которых балансим):

В OnCreated считываем PlayerResource:GetPlayerCount() (реальных).
playerFactor = playerCount / 2 (для 2 игроков = 1.0, для 1 = 0.5, для 4 = 2.0).
HP врагов домножаем на playerFactor → соло мало HP но тот же урон (умираешь быстро = почти непроходимо), вчетвером много HP но и DPS ×4 (легче).
Урон врагов домножаем слабо: dmg_mult *= (0.85 + 0.15*playerFactor) — чтобы соло урон оставался смертельным, а втроём/вчетвером не раздувался до абсурда.
Броню/МR/MS оставляем как в кривой (не зависят от игроков).
Это даёт: 1 игрок ≈ непроходимо, 2 = эталонная сложность, 3–4 = легче, но не тривиально.
